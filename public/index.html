        YouTube

        Para buscar e tocar vídeos do YouTube no app, cole uma chave de API grátis do Google:

        1. Abra YouTube Data API v3 e crie um projeto
        2. Toque em Ativar
        3. Vá em Credenciais → Criar credenciais → Chave de API
        4. Recomendado: restrinja a chave ao site gilsonbolivar-maker.github.io/*

        A cota grátis permite cerca de 100 buscas por dia. O YouTube só toca com o app aberto; não é possível baixar.
